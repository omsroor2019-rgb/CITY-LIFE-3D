# CITY LIFE 3D — مشروع اللعبة الكامل

لعبة عالم مفتوح ثلاثية الأبعاد أصلية، مكتوبة بلغة C باستخدام raylib 5.5 وقالب raymob لأندرويد.

## محتويات المجلد

```text
CITY-LIFE-3D/
├── .github/
│   └── workflows/
│       └── android-apk.yml
├── src/
│   └── main.c
├── .gitignore
├── LICENSE-CODE.txt
└── README-AR.md
```

## وظائف النموذج الموجود في `src/main.c`

- مدينة إجرائية صغيرة بثلاثة أبعاد.
- طرق وأرصفة ومبانٍ ونوافذ وأشجار.
- شخصية بمنظور الشخص الثالث.
- حركة مع تصادم أولي مع المباني وحدود المدينة.
- سيارة قابلة للركوب والقيادة والخروج.
- تسارع وفرامل وتوجيه.
- ثلاث مهمات توصيل ومكافآت مالية.
- عصا تحكم افتراضية وأزرار لمس.
- لا يعتمد النموذج الحالي على ملفات صور أو نماذج خارجية.

## ما الذي لا تتضمنه النسخة؟

هذه نسخة أولية قابلة للتطوير وليست لعبة بحجم GTA. لا تتضمن بعد شرطة أو حركة مرور أو مشاة مستقلين أو أسلحة أو حفظ تقدم دائم أو خريطة ضخمة أو نماذج عالية التفاصيل.

## كيف يتم بناء APK؟

ملف GitHub Actions في `.github/workflows/android-apk.yml` يقوم تلقائياً بما يلي:

1. تنزيل كود اللعبة من هذا المستودع.
2. تنزيل قالب Android الأصلي `KarvinJ/raylib-mobile`.
3. تثبيت Java 17 وأدوات Android SDK وNDK وCMake المطلوبة.
4. قبول تراخيص SDK عبر `android-actions/setup-android@v4`.
5. نسخ `src/main.c` إلى مجلد CMake الخاص بالقالب.
6. ضبط اسم التطبيق ومعرّفه وإعدادات الشاشة.
7. تشغيل Gradle لبناء نسخة Debug APK.
8. رفع APK كـ Artifact باسم `CITY-LIFE-3D-APK`.

قالب Android لا يُضمّن في هذا الأرشيف؛ يقوم GitHub Actions باستنساخه من مستودعه الرسمي أثناء البناء. لذلك يلزم اتصال إنترنت أثناء البناء.

## رفع المجلد إلى GitHub من هاتف Android

1. نزّل `CITY-LIFE-3D-FULL-PROJECT.zip` وفك ضغطه.
2. افتح مستودع GitHub `CITY-LIFE-3D`.
3. ارفع محتويات المجلد مع الحفاظ على المسارات. يجب أن يصل ملف البناء إلى:
   `.github/workflows/android-apk.yml`
   ويجب أن يصل كود اللعبة إلى:
   `src/main.c`
4. إذا كانت الملفات القديمة موجودة، استبدل محتوى `android-apk.yml` بمحتوى النسخة الموجودة هنا، واستبدل `src/main.c` بالنسخة الموجودة هنا.
5. احفظ التغييرات (Commit changes).
6. افتح تبويب Actions. يبدأ البناء تلقائياً بعد الدفع إلى فرع `main` أو `master`، ويمكن أيضاً تشغيله يدوياً عبر Run workflow.
7. عند نجاح العملية، افتح نتيجة التشغيل ونزّل Artifact باسم `CITY-LIFE-3D-APK`.
8. فك ضغط الـ Artifact وثبّت APK على الهاتف. قد تحتاج إلى السماح بالتثبيت من مدير الملفات.

## ملاحظات اختبار مهمة

- هذا الأرشيف يحتوي على كود اللعبة وملفات بناء المشروع، وليس APK جاهزاً.
- لم يتم تنفيذ بناء Android NDK/Gradle على هذا الجهاز أثناء إعداد الأرشيف. لذلك لا يمكن ضمان نجاح أول بناء قبل رؤية نتيجة GitHub Actions.
- نجاح إنشاء APK لا يغني عن اختباره على هاتف حقيقي من حيث اللمس والأداء والرسوميات.
- يستخدم قالب raymob وraylib من مستودعاتهما الأصلية. راجع تراخيص تلك المشاريع قبل إعادة توزيع اللعبة تجارياً.
